# AdScale — проектирование RTB-сервиса и интеграции с DSP

## О задании

Пакет документов детализирует критичный по SLA компонент архитектуры AdScale — Сервис ставок (Bidding Service), уже выделенный в отдельный сервис в рамках целевой архитектуры. Здесь описывается его внутреннее устройство: границы и API, контракт взаимодействия с Сервисом кампаний, протоколы взаимодействия с прочими зависимостями, дизайн API Gateway для интеграции с DSP-партнёрами, паттерны обеспечения надёжности и стратегия отказоустойчивости в условиях жёсткого SLA (P95 ≤ 80 мс, доступность ≥ 99,9%).

Документ в основном описывает систему в предположении, что целевая архитектура уже полностью развёрнута: Сервис ставок, Сервис кампаний, Сервис выдачи, Сервис статистики, Сервис аналитики и Финансовый сервис работают как независимые сервисы, а Kafka — технология потоковой обработки событий между ними. Отдельно, в `bidding-service.md`, описано, как контракт с Сервисом кампаний остаётся стабильным и на переходный период, пока часть сервисов ещё не выделена из монолита.

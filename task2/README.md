# AdScale — проектирование RTB-сервиса и интеграции с DSP

## О задании

Пакет документов детализирует критичный по SLA компонент архитектуры AdScale — Сервис ставок (Bidding Service), уже выделенный в отдельный сервис в рамках целевой архитектуры. Здесь описывается его внутреннее устройство: границы и API, протоколы взаимодействия с зависимостями, дизайн API Gateway для интеграции с DSP-партнёрами и паттерны обеспечения надёжности в условиях жёсткого SLA (P95 ≤ 80 мс, доступность ≥ 99,9%).

Документ описывает систему в предположении, что целевая архитектура уже полностью развёрнута: Сервис ставок, Сервис выдачи, Сервис статистики, Сервис аналитики и Финансовый сервис работают как независимые сервисы, а Kafka — технология потоковой обработки событий между ними. Переходное состояние миграции (порядок и способ выделения сервисов из монолита) в этом пакете не рассматривается.

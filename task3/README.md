# AdScale — данные, масштабирование и отказоустойчивость

## О пакете

Пакет описывает стратегию работы с данными для пяти сервисов AdScale (RTB-платформы цифровой рекламы) в микросервисной архитектуре: Сервис ставок, Сервис кампаний, Сервис статистики, Сервис аналитики, Сервис финансов. Для каждого сервиса выбран тип хранилища, спроектированы стратегии масштабирования (репликация, шардирование, CQRS), кэширования, потоковой обработки событий и отказоустойчивости (RPO/RTO, резервное копирование).

**Контекст нагрузки:** до 50 000 запросов на ставку в секунду (RPS) на целевом этапе, требование P95 времени отклика ≤ 80 мс на пути обработки bid-запроса, доступность (SLA) ≥ 99,9%.
